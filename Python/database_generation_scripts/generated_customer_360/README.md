# Generated Customer 360 CSV and JSON Data

## Purpose

This directory contains generated customer-level extracts that consolidate accounts, loans, cards, deposits, insurance, investments, and a combined JSON view.

## Contents

| Item | Description |
| --- | --- |
| `customers.csv` | Customer records included in the generated 360 dataset. |
| `customer_accounts.csv` | Account-level holdings. |
| `customer_credit_cards.csv` | Credit card holdings. |
| `customer_debit_cards.csv` | Debit card holdings. |
| `customer_loans.csv` | Loan holdings. |
| `customer_deposits.csv` | Deposit holdings. |
| `customer_insurance.csv` | Insurance holdings. |
| `customer_investments.csv` | Investment holdings. |
| `customer_360.json` | Combined structured customer 360 representation. |

## Operational Notes

Regenerate these files through the generation pipeline rather than hand-editing large derived datasets.
