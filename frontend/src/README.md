# Frontend Source

## Purpose

This directory contains the React application entry points, routing, styles, pages, components, context, and API service layer.

## Contents

| Item | Description |
| --- | --- |
| `main.jsx` | Mounts the React application. |
| `App.jsx` | Defines top-level routes and application layout. |
| `App.css and index.css` | Global and application styles. |
| `pages/` | Route-level screens. |
| `components/` | Reusable presentational and layout components. |
| `contexts/` | Shared React state providers. |
| `services/` | HTTP API integration layer. |

## Operational Notes

Keep route-level data loading in pages or services and keep reusable visual elements in components.
