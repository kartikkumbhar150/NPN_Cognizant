# Frontend Pages

## Purpose

This directory contains route-level screens in the employee dashboard.

## Contents

| Item | Description |
| --- | --- |
| `Login.jsx` | Employee login page. |
| `Dashboard.jsx` | Main overview page. |
| `Customers.jsx` | Customer list and discovery page. |
| `Customer360.jsx` | Detailed customer profile and intelligence page. |
| `Campaigns.jsx` | Campaign creation and management page. |
| `CampaignAnalytics.jsx` | Campaign-specific analytics page. |
| `Analytics.jsx` | General analytics page. |
| `Segments.jsx` | Customer segmentation page. |

## Operational Notes

Pages may compose components and call services. Keep page names aligned with route responsibilities.
