# Frontend Components

## Purpose

This directory contains reusable React components shared across dashboard pages.

## Contents

| Item | Description |
| --- | --- |
| `Header.jsx` | Top navigation and page header component. |
| `Sidebar.jsx` | Application side navigation. |
| `KpiCard.jsx` | Reusable metric card. |
| `CampaignSuccessModal.jsx` | Campaign completion feedback modal. |
| `OfferSuccessModal.jsx` | Offer action feedback modal. |

## Operational Notes

Components should remain reusable and avoid duplicating backend API calls that belong in pages or services.
