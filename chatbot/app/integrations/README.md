# Chatbot Integrations

## Purpose

This directory contains adapter code for integrating the chatbot with the existing banking AI engine without tightly coupling service internals.

## Contents

| Item | Description |
| --- | --- |
| `ai_engine_adapter.py` | Loads and invokes read-only AI engine functionality for customer-aware recommendations. |
| `__init__.py` | Marks the directory as a Python package. |

## Operational Notes

Use this directory as part of the documented application workflow. Keep generated files, secrets, and environment-specific artifacts out of source control unless they are intentional sample data.
