# Chatbot Models

## Purpose

This directory contains strict data contracts for chatbot requests, responses, recommendations, sources, and related metadata.

## Contents

| Item | Description |
| --- | --- |
| `chat_models.py` | Pydantic models used by API routes and response mapping. |
| `__init__.py` | Marks the directory as a Python package. |

## Operational Notes

Use this directory as part of the documented application workflow. Keep generated files, secrets, and environment-specific artifacts out of source control unless they are intentional sample data.
